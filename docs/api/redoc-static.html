Request Body schema: application/json
required
farmId
required
string <uuid>
name
required
string <= 150 characters
areaHa
required
number >= 0.01
cropType
required
string (TypeCulture)
Enum: "olive" "citrus" "cereal" "vegetable" "other"
soilType
required
string (TypeSol)
Enum: "clay" "silt" "sandy" "calcareous" "mixed"
irrigationMethod
required
string (MethodeIrrigation)
Enum: "drip" "sprinkler" "gravity"
cropVariety
string or null <= 100 characters
flowRateM3h
number or null >= 0
treeAgeYears
number or null >= 0
treeDensityPerHa
number or null >= 0
object (GeoJsonPoint)

Point GeoJSON — coordonnées au format [longitude, latitude] (WGS84)

object (GeoJsonPolygon)

Polygone GeoJSON — coordinates est une liste d'anneaux (linear rings), chaque anneau une liste de positions [longitude, latitude], le premier anneau étant le contour extérieur.
